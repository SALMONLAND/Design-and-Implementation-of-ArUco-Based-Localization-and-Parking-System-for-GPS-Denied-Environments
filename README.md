# ArUco 기반 실내 자율주차 시스템 연구

## 1. 개요

본 연구는 GPS 신호가 차단되는 실내 환경에서 ArUco 마커를 활용한 자율주차 시스템을 설계하고 구현한다. 기존 실외 자율주행 기술은 GPS 기반 위치 측위에 의존하나, 지하주차장과 같은 실내 공간에서는 이러한 방식이 불가능하다. 이에 대한 대안으로 시각 기반 마커 인식 기술을 적용하여 차량의 위치 파악, 경로 추종, 정밀 주차를 수행하는 시스템을 제안한다.

시스템은 라즈베리파이 기반 비전 처리 모듈과 아두이노 기반 모터 제어 모듈로 구성된다. 상향 카메라로 천장에 부착된 ArUco 마커를 인식하여 현재 위치를 파악하고, 전방 카메라로 주차 공간 마커를 감지하여 PID 제어 기반 정밀 주차를 수행한다.


## 2. 연구 목표

본 연구의 핵심 목표는 다음과 같다.

**#1. 위치 측위 정확도 확보**: ArUco 마커 인식을 통해 GPS 없이도 실내에서 차량의 절대 위치와 방향을 파악한다. 마커 ID 체계를 구역별로 분류하여 천장 마커는 경로 추종에, 벽면 마커는 방향 전환 트리거에, 주차 공간 마커는 점유 상태 판단과 정밀 주차에 활용한다.

**#2. 정밀 주차 성능 달성**: PID 제어를 적용하여 주차 완료 시 위치 오차 ±5cm 이내, 각도 오차 ±3° 이내를 목표로 한다. X축, Y축, 각도에 대해 각각 독립적인 PID 컨트롤러를 운용하며, 우선순위 기반 제어 전략을 통해 안정적인 정렬을 수행한다.

**#3. 자율 운영 시스템 구현**: 입구 진입부터 빈 주차 공간 탐색, 주차, 출차까지 전 과정을 자동화한다. 상태 머신 구조를 적용하여 탐색, 주차, 대기, 출차 모드 간 전환을 명확히 정의한다.


## 3. 동작 흐름

### 3.1 시스템 구성

시스템은 비전 처리부와 모터 제어부로 이원화된다.

비전 처리부는 라즈베리파이에서 동작하며, 카메라로부터 영상을 입력받아 ArUco 마커를 감지한다. 감지된 마커의 ID, 중심 좌표, 회전 각도를 계산하여 JSON 형식으로 직렬화한 후 시리얼 통신을 통해 아두이노로 전송한다. 부가적으로 HSV 색공간 기반 색상 감지를 수행하여 주차 공간의 점유 상태를 보조적으로 판단한다.

모터 제어부는 아두이노에서 동작하며, 수신된 마커 데이터를 기반으로 상태 머신을 갱신하고 모터 출력을 결정한다. 4륜 탱크 구동 방식을 채택하여 좌측 2개, 우측 2개 모터를 동기화하며, 좌우 모터의 역방향 구동으로 제자리 회전이 가능하다.

### 3.2 마커 ID 체계

마커는 용도에 따라 ID 범위를 구분한다.

천장 마커는 ID 0번부터 99번까지 할당되며, 주차장 내 경로를 정의한다. 차량은 이 마커를 추종하며 전진한다. 마커 중심이 카메라 중심에서 벗어난 정도에 비례하여 좌우 모터 속도를 차등 적용함으로써 경로를 유지한다.

벽면 마커는 ID 100번부터 149번까지 할당되며, 방향 전환 지점을 표시한다. ID 100번부터 124번까지는 좌회전, 125번부터 149번까지는 우회전을 지시한다. 차량은 해당 마커를 감지하면 제자리 회전을 수행한 후 전진을 재개한다.

주차 공간 마커는 ID 150번부터 199번까지 할당된다. 홀수 ID는 빈 공간을, 짝수 ID는 점유 상태를 나타낸다. 차량은 홀수 ID 마커를 감지하면 주차 모드로 전환하고, 짝수 ID 마커는 무시하고 통과한다.

입구 마커는 ID 200번으로 고정되며, 주차장 진입 및 퇴장 지점을 표시한다. 출차 모드에서 이 마커를 감지하면 시스템은 동작을 종료한다.

### 3.3 상태 머신

시스템은 5개의 상태로 운영된다.

대기 상태는 시스템 초기 상태이다. 외부 명령을 수신하기 전까지 모터를 정지 상태로 유지한다.

탐색 상태는 빈 주차 공간을 찾는 단계이다. 천장 마커를 추종하며 전진하고, 벽면 마커에서 방향을 전환한다. 주차 공간 마커를 감지하면 ID의 홀짝을 판별하여 빈 공간일 경우 주차 상태로 전환한다.

주차 상태는 PID 제어를 통해 차량을 주차 공간에 정렬하는 단계이다. 마커 중심과 카메라 중심 간의 오차, 그리고 마커와 차량 간의 각도 오차를 최소화한다. 모든 오차가 허용 범위 내에 들어오면 주차 완료 상태로 전환한다.

주차 완료 상태는 차량이 정렬을 완료하고 대기하는 단계이다. 출차 명령을 수신할 때까지 모터를 정지 상태로 유지한다.

출차 상태는 주차 공간에서 후진하여 통로로 진입한 후, 천장 마커를 추종하며 입구로 이동하는 단계이다. 입구 마커를 감지하면 대기 상태로 복귀한다.

### 3.4 PID 제어 구조

정밀 주차를 위해 3개의 독립적인 PID 컨트롤러를 운용한다.

X축 컨트롤러는 마커 중심의 수평 위치를 목표값으로 설정하고, 현재 감지된 마커의 X 좌표를 입력으로 받는다. 출력값은 좌우 모터 속도 차이로 변환되어 차량을 횡방향으로 이동시킨다. 비례 이득 1.2, 적분 이득 0.1, 미분 이득 0.5를 적용한다.

Y축 컨트롤러는 마커 중심의 수직 위치를 목표값으로 설정한다. 출력값은 전후진 속도로 변환된다. 비례 이득 1.0, 적분 이득 0.08, 미분 이득 0.4를 적용한다.

각도 컨트롤러는 마커와 차량 간의 상대 각도를 0도로 수렴시킨다. 출력값은 좌우 모터의 역방향 구동량으로 변환되어 제자리 회전을 수행한다. 비례 이득 3.0, 적분 이득 0.2, 미분 이득 1.0을 적용한다.

제어 우선순위는 각도, Y축, X축 순서로 설정한다. 각도 오차가 허용 범위를 초과하면 회전 보정만 수행하고, 각도가 정렬된 후에 전후 위치를 보정하며, 마지막으로 좌우 위치를 미세 조정한다. 이러한 순차적 접근은 제어 간섭을 최소화하고 수렴 속도를 향상시킨다.

### 3.5 모터 제어 방식

4륜 탱크 구동 방식을 채택한다. 좌측 전방, 좌측 후방, 우측 전방, 우측 후방 총 4개 모터를 사용하며, 좌측 2개와 우측 2개를 각각 동기화하여 제어한다.

전진과 후진은 4개 모터를 동일 방향으로 구동한다. 제자리 회전은 좌측과 우측 모터를 역방향으로 구동하여 수행한다. 좌측 모터 후진, 우측 모터 전진 시 좌회전이 발생하고, 그 반대의 경우 우회전이 발생한다.

곡선 주행은 좌우 모터 속도에 차등을 두어 구현한다. 천장 마커 추종 시 마커가 카메라 중심의 좌측에 위치하면 우측 모터 속도를 높이고, 우측에 위치하면 좌측 모터 속도를 높여 경로를 보정한다.

### 3.6 비전 처리

ArUco 마커 감지는 OpenCV 라이브러리의 aruco 모듈을 활용한다. 6x6 비트 패턴의 250개 마커 사전을 사용하며, 입력 영상을 그레이스케일로 변환한 후 마커 검출 알고리즘을 적용한다.

마커의 중심 좌표는 4개 코너 좌표의 평균으로 계산한다. 마커의 회전 각도는 상단 중점과 하단 중점을 연결하는 벡터의 방향으로 산출한다. 수직 상방을 0도로 정의하고, 시계 방향을 양의 각도로 정의한다.

색상 감지는 HSV 색공간에서 수행한다. 빨간색, 초록색, 파란색, 흰색에 대해 각각 색상, 채도, 명도 범위를 정의하고, 해당 범위에 속하는 픽셀 수를 계수한다. 최다 픽셀 수를 가진 색상을 감지 결과로 반환하며, 최소 임계값 이하일 경우 미감지로 처리한다.

### 3.7 통신 프로토콜

라즈베리파이와 아두이노 간 통신은 USB 시리얼을 사용하며, 115200 보드레이트로 설정한다. 데이터는 JSON 형식으로 직렬화하여 개행 문자로 구분한다.

라즈베리파이에서 아두이노로 전송하는 데이터는 두 종류이다. 마커 데이터는 ID, X 좌표, Y 좌표, 각도를 포함한다. 명령 데이터는 시작, 정지, 출차 명령을 전달한다.

아두이노에서 라즈베리파이로 전송하는 데이터는 현재 상태 정보이다. 탐색 중, 주차 중, 주차 완료, 출차 완료 등의 상태 문자열과 함께 디버그용 오차 정보를 포함할 수 있다.

타임아웃은 500밀리초로 설정한다. 마커 데이터 수신이 이 시간을 초과하면 탐색 및 출차 상태에서는 저속 전진을 유지하고, 주차 상태에서는 모터를 정지한다.


## 4. 결론

본 연구는 ArUco 마커 기반 실내 자율주차 시스템의 설계 및 구현 방안을 제시하였다. 마커 ID 체계를 통해 경로, 방향 전환 지점, 주차 공간을 구조적으로 정의하고, 상태 머신을 통해 탐색부터 출차까지의 전 과정을 체계화하였다. PID 제어의 우선순위 기반 적용으로 정밀 주차 성능을 확보하고, 4륜 탱크 구동으로 제자리 회전을 활용한 효율적인 방향 전환을 구현하였다.

향후 연구에서는 다중 마커 동시 인식을 통한 위치 정확도 향상, 장애물 감지 센서 융합, 다중 차량 운용을 위한 충돌 회피 알고리즘 적용을 검토할 수 있다.
